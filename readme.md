# 🚇 부산 지하철 역별 이용객 수 지도 분석 앱

Streamlit과 Folium을 활용하여 부산 지하철 1\~4호선 역별 이용객 수를 지도 위에 시각화하는 데이터 분석 웹 애플리케이션입니다.

\---

## 📌 주요 기능

1. **데이터 업로드 및 시각화**

   * CSV 파일(`busan\_subway.csv`)을 업로드하여 데이터를 불러오고 표 형태로 확인합니다.
2. **이용객 수 상위 5개 역 안내**

   * 이용객 수가 가장 많은 TOP 5 지하철역을 정리하여 표로 표시합니다.
3. **호선 필터링 (Multi-select)**

   * 1호선부터 4호선까지 원하는 호선만 선택하여 지도에 표시할 수 있습니다.
4. **대화형 지도 시각화 (Folium)**

   * **원의 크기**: 이용객 수의 제곱근에 비례하여 마커 크기를 자동으로 조절합니다.
   * **호선별 색상**:

     * 🟧 1호선: 주황색 (`orange`)
     * 🟩 2호선: 초록색 (`green`)
     * 🟫 3호선: 갈색 (`brown`)
     * 🟦 4호선: 파란색 (`blue`)
   * **인터랙션**:

     * 마우스 호버(Hover): 역명 및 호선 정보 표시
     * 클릭(Click): 해당 역의 상세 이용객 수 표시

## 🛠️ 실행 방법

### 1\. 필수 라이브러리 설치

```bash
pip install -r requirements.txt
```

### 2\. 앱 실행

```bash
streamlit run app.py
```
